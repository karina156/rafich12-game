# RAFICH12_: THE BIRTHDAY INCIDENT

«Раф против Макаки. Основано на реальном дне рождения».
Пиксельная браузерная игра-подарок на React + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (и адрес в сети — можно открыть с телефона в той же Wi-Fi)
npm run build      # сборка в папку dist/
npm run preview    # посмотреть собранную версию
```

Собранную папку `dist/` можно выложить на любой статический хостинг (Netlify, Vercel, GitHub Pages) — пути относительные.

## Ссылка на Telegram-стикерпак

Кнопка «ЗАБРАТЬ СТИКЕРПАК В ТГ ♡» ведёт на https://t.me/addstickers/rafini_love (задано в `src/config.ts`).
Другую ссылку и дату дня рождения можно указать в `.env` (скопируй `.env.example`):

```
VITE_TELEGRAM_STICKERPACK_URL=https://t.me/addstickers/имя_пака
VITE_BIRTHDAY_DATE=MM-DD        # день рождения Рафи, для достижения «УЖЕ ДЕД»
```

После изменения `.env` перезапусти `npm run dev` или пересобери `npm run build`.

## Картинки

Картинки из папок karina уже лежат в `public/assets/` (уменьшены до размера, нужного игре). Полный список файлов и путей — в **ASSETS.md**.
Корзиной в «Подарочном дожде» служит полураскрытый сундук. Необязательные картинки, которых нет (фоны кат-сцены и выбора, промежуточные чашки),
заменяются градиентом или соседней картинкой. Фон `rewards/final_bg.png` (background.png) стоит вместо тёмных подложек везде.
Перед каждым уровнем экран загрузки с Карини ждёт, пока прогрузятся картинки уровня (`src/components/LoadingScreen.tsx`).

Как устроено:

- Каждый PNG кладётся в `public/assets/...` по пути из `src/data/assets.manifest.json`. Код трогать не нужно.
- Пока файла нет, на его месте видна полосатая заглушка с подписью и путём — это не ассет, а напоминание, что положить.
- Эмоции персонажей — отдельные файлы: `characters/karini/happy.png`, `characters/monkey/laugh.png` и т.д.
  Если в Figma эмоции на одном листе (sprite sheet), их нужно нарезать на отдельные PNG.
- Стикеры: `public/assets/stickers/sticker_01.png`, `sticker_02.png`, … — галерея находит их сама.
- Рамки и кнопки (`ui/button.png`, `ui/dialog_frame.png`, `ui/panel.png`) подключаются как `border-image` автоматически,
  толщина среза настраивается в `src/styles/variables.css` (`--skin-slice-*`).
- Расстановка мебели в комнате — `src/data/roomLayout.ts` (координаты в сцене 960×540).
- `npm run assets:check` — какие файлы ещё не положены; `npm run assets:doc` — пересобрать ASSETS.md.

## Музыка и звуки

Эффекты синтезируются через Web Audio API. Можно заменить файлами `public/assets/sounds/<событие>.mp3`.
Фоновая музыка — `public/assets/sounds/music.mp3` (пока её нет, играет тихий синтезированный луп).
Звук включается только после первого нажатия (политика браузеров). Переключатели звука и музыки — в HUD и в паузе.

## Телефоны

На телефонах (сенсорный экран, короткая сторона меньше 600px) игра не запускается: вместо неё открытка со стикером
и рамкой «С ДР, Рафи!!» и подсказкой открыть ссылку на планшете или компьютере. Проверка — `src/scenes/PhoneScreen.tsx`.

## Как устроена игра

- Сцена масштабируется целиком (короткая сторона 540 логических px), поэтому у спрайтов один масштаб на любом экране.
  На телефоне вертикально HUD и панели перестраиваются, подсказка предлагает повернуть телефон, но играть можно и так.
- Каждый уровень проходит фазы introduction → playing → victory → completed, при поражении — retry.
  Игра внутри перемонтируется на каждую попытку, так что таймеры и циклы не утекают.
- Награды (монеты, предметы, достижения уровня) выдаются только при первом прохождении; перепроходить можно сколько угодно.
- Уже просмотренные диалоги можно пропустить кнопкой «ПРОПУСТИТЬ» (или Esc).
- Пауза: кнопка ⚙ / ❚❚ или Esc. Там же звук, достижения, выход в комнату и сброс прогресса.
- Кофейный уровень необязателен: финал проходится и без него. Открывается 5 нажатиями на кофемашину.

## Что проверено

`npm run build` проходит без ошибок TypeScript. Игра прогнана автоматически в Chromium (Playwright)
от экрана запуска до посткредитов на трёх экранах: компьютер 1280×720, планшет вертикально 820×1180 и горизонтально 1180×820.
На телефонных размерах (390×844 и 844×390 с касаниями) проверено, что вместо игры открывается открытка.
Ошибок в консоли не было. Проверено:

- загрузка, пропуск boot-экрана, вступительная кат-сцена с glitch и кражей подарка, кнопка «Я просто хотел отметить др...»;
- выбор Рафа стрелками, сохранение выбора;
- комната: закрытые уровни показывают, что пройти сначала; объекты появляются по мере прохождения;
- Подарочный дождь: бот ловит 19 подарков корзиной; при бездействии время выходит → экран «Попытка провалена» → «Ещё раз» сбрасывает уровень;
- Торт: странный и нормальный рецепт, разные достижения;
- 19 свечей: сбор свечей, задувание, Макака зажигает свечи обратно, экран MAKE A WISH;
- Коробки: 3 раунда с ускорением, ошибка повторяет только текущий раунд;
- Праздничный хаос: 3 волны, шкала хаоса, PARTY RESTORED, комната становится праздничной;
- Кофейня: открывается 5 нажатиями на чашку кофе, Карини подсказывает следующий шаг, ошибка даёт реплику про «Артёма на овсяном», правильный рецепт даёт РАФ²;
- Босс: уклонение от бананов (12 уклонений), пошаговый бой, фаза 3, кофейная ульта;
- финал: сундук (3 спрайта), окно «ссылка не задана», посткредиты и три кнопки;
- перезагрузка страницы: прогресс и комната восстанавливаются, посреди уровня — возврат в комнату;
- перепрохождение уровня не начисляет монеты повторно; пауза останавливает таймер; «Пропустить» на уже виденных диалогах.

## Ограничения

- Стикер в галерее пока один.
- Достижение «УЖЕ ДЕД» работает только если указать `VITE_BIRTHDAY_DATE`.
- Звук проверялся только на отсутствие ошибок: в автотесте его не слышно.
- На реальных планшетах и телефонах не запускалось, только эмуляция размеров экрана и касаний в Chromium.
